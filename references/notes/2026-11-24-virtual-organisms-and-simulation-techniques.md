**Has anyone built a virtual Aplysia?** No. Web, PubMed and GitHub searches found no whole-animal Aplysia simulation, no Aplysia connectome, and no published whole-nervous-system single-cell atlas. From Moroz only a [2018 perspective](https://doi.org/10.1021/acschemneuro.8b00100) proposing whole-brain single-cell sequencing could be confirmed. The closest things are the Chiel/Webster-Wood feeding models (embodied, no learning) and the Byrne lab's [13-cell feeding-circuit model with reward plasticity](https://doi.org/10.1101/lm.051367.120) (no body). Two hobby repositories exist (ogorangeduck/aplysioid; an Izhikevich pedal-ganglion model by JavieraRojasM); descriptions only were seen.

## B. Simulation techniques

| Technique | Source | Idea | Reported gain |
|---|---|---|---|
| Clock- vs event-driven | [Brette 2007](https://doi.org/10.1007/s10827-007-0038-6) | Clock-driven cost is c_U·N/dt + c_P·F·N·p; event-driven cost scales with spikes only and needs solvable neuron models | At 1 Hz, 10⁴ synapses, 0.1 ms, state updates dominate. A 0.1 ms clock-driven LIF run gave about 10% higher rates than the exact event-driven run |
| Delays | Brette 2007; [Pronold 2022](https://doi.org/10.3389/fninf.2021.785068) | Circular array indexed (p+d) mod n; NEST keeps one ring buffer per neuron holding summed weights | Delay cost described as small |
| Synapse layout and delivery | [Kunkel 2014](https://doi.org/10.3389/fninf.2014.00078); [Jordan 2018](https://doi.org/10.3389/fninf.2018.00002) (abstracts); Pronold 2022; [cache follow-up](https://arxiv.org/abs/2109.12855) | Synapses stored per thread and type, sorted by source into contiguous target segments. Spikes sorted before delivery; synapses point straight at the ring buffer; prefetching | Delivery instructions halved, run time down up to 40%; prefetching up to 50% |
| STDP bookkeeping | [Morrison 2008](https://doi.org/10.1007/s00422-008-0233-1); [Knight & Furber 2016](https://doi.org/10.3389/fnins.2016.00420); [Bautembach 2021](https://arxiv.org/abs/2107.04092) | Two traces replace spike histories; weights change only at spikes. SpiNNaker defers updates until a presynaptic spike arrives, using a 10-entry postsynaptic history. Lazy, bitfield-based updates. Pseudo-code is in [Morrison 2007](https://doi.org/10.1162/neco.2007.19.6.1437) (abstract only) | 4× more neurons per SpiNNaker core at 8000 STDP inputs; lazy STDP 1.5–2× |
| Procedural connectivity | [Knight & Nowotny 2021](https://doi.org/10.1038/s43588-020-00022-7) | Regenerate connectivity and weights on the fly instead of storing them | 4.13×10⁶ neurons and 24.2×10⁹ synapses on one GPU |
| Precision and Izhikevich numerics | [Hopkins & Furber 2015](https://doi.org/10.1162/NECO_a_00772); [Hopkins 2020](https://doi.org/10.1098/rsta.2019.0052); [Pauli 2018](https://doi.org/10.3389/fninf.2018.00046) | Merge solver and equation into one formula; correct threshold-crossing lag; stochastic rounding. Izhikevich's original 1 ms scheme is numerically unstable | Fixed-point with stochastic rounding beat single-precision float. Polychronous groups fell from 4,300 to 151 at 0.1 ms |
| Code generation and vectorisation | [Goodman 2010](https://doi.org/10.1007/s12021-010-9082-x); [Brette & Goodman 2011](https://doi.org/10.1162/NECO_a_00123) | Generate low-level code from high-level equations; vectorise over neurons | Qualitative only in abstracts |
| Gap junctions | [Hahne 2015](https://doi.org/10.3389/fninf.2015.00022); [Jordan 2020](https://doi.org/10.3389/fninf.2020.00012) | Waveform relaxation keeps electrical coupling compatible with delayed spike exchange | More than an order of magnitude faster at scale |
| Neuromorphic hardware | Knight & Furber 2016; [Loihi 2](https://arxiv.org/abs/2111.03746); [SpiNNaker2](https://arxiv.org/abs/2401.04491) (abstract only) | SpiNNaker: fixed 1 ms neuron step, synaptic rows fetched per spike. Loihi 2: microcode-programmable fixed-precision neurons, 32-bit graded spikes | Up to 8192 neurons per Loihi 2 core |

## Implications for this project

- **Adopt first** (inference from Brette and the NEST papers): a fixed-step clock-driven loop, a per-neuron delay ring buffer, and synapses in source-sorted contiguous arrays.
- **STDP:** use trace-based updates at spike times only. The SpiNNaker deferred scheme suits source-sorted storage because it avoids column lookups on postsynaptic spikes.
- **Izhikevich numerics:** do not hard-code 1 ms Euler. Make the step configurable, keep a float64 reference mode, and test smaller steps and several seeds, as Pauli recommends.
- **Skip for now:** procedural connectivity and exascale layouts target 10⁶+ neurons. Aplysia is roughly 10⁴ (8,000–10,000 per a search snippet of the NeuronBank paper, *unopened*). Plan for gap junctions; the feeding circuit has electrical coupling.
- **Imitate:** Shiu 2024 for validation (prediction-versus-experiment table, stated limitations), OpenWorm for packaging, BAAIWorm for closing the loop, and Chiel/Webster-Wood for the Aplysia body.
- **Aplysia data:** there is no connectome. Use the Byrne feeding model (ModelDB 261489) and the older ModelDB Aplysia models (seen in a GitHub listing), the CRCNS pedal recordings, [transmitter maps](https://doi.org/10.1101/lm.053758.123), and the Carnegie Mellon feeding repositories.
